# 坐席绩效业绩排行榜（Web 看板）

一个用于大屏展示的坐席绩效业绩排行榜单页应用，纯静态、零依赖、可直接部署到 GitHub Pages 公网访问。

## 功能
- **说明栏**：注明“未包含质量、考勤等数据，以最终绩效计算结果为准”及数据期间。
- **切换器**：全部 / 综合 / 人社 / 公教企 / 工单。
- **搜索器**：按姓名实时筛选。
- **榜单**：固定表头 + 缓慢自动滚动（鼠标悬停暂停），自动轮播顺序为 全部→综合→人社→公教企→工单。
- **表头**：序号、姓名、列队、报表话务量、漏接回拨、计奖话务量、排名（按绩效奖金）、绩效奖金。
- **绩效奖金**：严格按桌面《绩效奖金计算.xlsx》的区间映射显示（计奖话务量 → 奖金档）。
- **24 套 UI 主题**：右侧隐藏悬浮球，点击展开选择（含政务蓝、海洋青、墨韵、赛博、星河等）。
- **自适应**：电脑 / 平板 / 手机（响应式 + 移动端粘性首列）。

## 数据
- 模拟数据：综合 100 人、人社 100 人、公教企 100 人、工单 35 人，共 335 人。
- 重新生成：`python gen_data.py`（需先 `pip install openpyxl` 仅用于解析规则；本仓库数据已生成）。
- 修改数据期间：编辑 `index.html` 中 `const PERIOD = '...'` 或 `template.html` 后重新生成。

## 本地预览
直接用浏览器打开 `index.html` 即可；或起一个静态服务：
```
python -m http.server 8080
# 访问 http://localhost:8080
```

## 部署到 GitHub Pages
见 `deploy.sh`：提供 GitHub 用户名与个人访问令牌（PAT，需 `repo` 权限）即可一键创建公开仓库并开启 Pages。
```
bash deploy.sh <GitHub用户名> <PAT> [仓库名]
```
部署完成后访问：`https://<用户名>.github.io/<仓库名>/`
